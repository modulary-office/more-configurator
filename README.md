# MORE Configurator

מנוע קונפיגורטור תלת־ממד של MORE by MODULARY.
מנוע אחד משרת את כל המוצרים: כל מוצר מוגדר בקובץ JSON משלו (אפשרויות, ברירות מחדל, מחירים), והגאומטריה נבנית בקוד לפי "משפחה" (שולחנות Bench, ובהמשך ארונות, בוטים, כיסאות וספות).

## מבנה התיקייה

| נתיב | מה יש בו |
|---|---|
| `products/*.json` | קובץ לכל מוצר: שם, אפשרויות, ברירות מחדל, **כללי מחיר** |
| `catalogs/*.json` | רשימות משותפות לכל המוצרים: דקורים (`decors`), צבעי RAL (`ral`), בדים (`fabrics`) |
| `src/engine/` | המנוע: תצוגה תלת־ממד, פאנל האפשרויות, תמחור, קישור שיתוף |
| `src/families/` | משפחות מוצרים. `bench.js` = שולחנות Bench (Duo Bench). `cabinet.js` = ארונות, כונניות, כוורות, יחידות מגירה, שלוחות, דלפקים ומטבחונים. `desk.js` = שולחנות עבודה ושלדי מתכת |
| `models/` | קבצי GLB (כיסאות וספות, בהמשך) |
| `dist/mrcfg.min.*` | הגרסה המכווצת של המנוע – זה מה שהאתר טוען |
| `dist/duo-bench.min.*` | הגרסה הישנה (1.0.x). נשארת כדי שדפים ישנים ימשיכו לעבוד |
| `examples/` | דף דמו וקוד ההטמעה |

## הטמעה בדף מוצר

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/modulary-office/more-configurator@v1.3.0/dist/mrcfg.min.css">
<div id="mrcfg-mount" data-product="duo-bench" data-name="Duo Bench" data-quote="/contact/"></div>
<script type="module" src="https://cdn.jsdelivr.net/gh/modulary-office/more-configurator@v1.3.0/dist/mrcfg.min.js"></script>
```

- `data-product` – שם קובץ המוצר בתיקייה `products` (בלי `.json`).
- `data-name` – לא חובה. גובר על השם שבקובץ המוצר.
- `data-quote` – כתובת דף יצירת הקשר. הסיכום נשלח אליה כפרמטר `subject`.

המאגר חייב להיות ציבורי כדי ש־jsDelivr יגיש אותו. בכל Release חדש מעדכנים את מספר הגרסה (`@v1.3.0`) בשתי השורות.

## מחירים

המחירים נמצאים בקובץ המוצר, תחת `pricing.rules`. כל הסכומים מתחילים ב־0.
**כל עוד הסכום הכולל הוא 0, הלקוח לא רואה מחיר.** ברגע שמזינים מחירים, מופיעה שורת "מחיר משוער" מעל קוד התצורה, והמחיר נכנס גם לבקשת הצעת המחיר.

הכללים מחושבים לפי הסדר שבו הם כתובים. כל כלל יכול לקבל `when` – תנאי שרק כשהוא מתקיים הכלל נספר, למשל `"when": { "tray": true }` או `"when": { "sh": [30, 40, 50] }`.

| סוג (`type`) | מה הוא עושה | שדות |
|---|---|---|
| `fixed` | סכום קבוע | `amount` |
| `unit` | סכום ליחידה × כמות | `per`, `amount` |
| `area` | סכום למ״ר משטח | `amount` |
| `length` | סכום למטר אורך | `amount` |
| `option` | סכום לפי הבחירה (דקור, צבע…) | `key`, `amounts`, `otherwise`, `per` (לא חובה) |
| `percent` | אחוז מהסכום שנצבר עד כה (שלילי = הנחה) | `percent` |
| `tiers` | מדרגות לפי ערך | `by`, `tiers: [{ "upTo": 2.4, "amount": 0 }]` |
| `qtyDiscount` | הנחת כמות | `by`, `tiers: [{ "from": 8, "percent": 5 }]` |
| `customSize` | תוספת למידה שהלקוח הקליד | `key`, `amount`, `percent` |

הכמויות שאפשר להשתמש בהן ב־`per` וב־`by` (ל־Duo Bench):
`seats` עמדות · `stations` עמדות בכל צד · `lengthM` אורך במטרים · `areaM2` שטח המשטח במ״ר · `screens` מספר מחיצות · `screenAreaM2` שטח בד המחיצות · `powerBoxes` קופסאות חשמל.

דוגמה – 650 ₪ למ״ר אגוז, 420 ₪ למ״ר לשאר הדקורים:

```json
{ "type": "option", "label": "פלטה לפי מ״ר", "key": "top", "per": "areaM2", "amounts": { "walnut": 650 }, "otherwise": 420 }
```

## מוצרי ארונות (גרסה 1.2)

| קובץ | מוצר |
|---|---|
| `cabinet-tall` | ארון גבוה |
| `cabinet-low` | ארון נמוך |
| `cabinet-sliding` | ארון דלתות הזזה |
| `shelf-open` | כוננית (פתוחה / עם דלתות תחתונות / זכוכית) |
| `cubby` | כוורת תאים |
| `drawer-unit` | יחידת מגירות ועגלה |
| `file-cabinet` | ארון תיקיות |
| `credenza` | שלוחת מנהל |
| `counter` | דלפק קבלה (ישר / פינתי) |
| `kitchenette` | מטבחון לפי מטר רץ |

בקבצים האלה הסכומים הם **מחירי הספק לפני מע״מ**, כמו במחירון. בראש `pricing` שלוש הגדרות:
`markup` – אחוז רווח (100 = פי 2), `vat` – מע״מ באחוזים, `roundTo` – עיגול (10 = לעשרות). המחיר ללקוח = מחירון × (1 + רווח) × (1 + מע״מ), מעוגל.

כרגע מוגדר בכל מוצרי הארונות `"customQuote": true`: מידה שהלקוח מקליד (כפתור "אחר") לא מקבלת מחיר אוטומטי, ובמקומו מוצג "לפי הצעת מחיר". כדי להחזיר תמחור אוטומטי למידות מיוחדות, מוחקים את השורה הזו או משנים ל־false.

כלל מסוג `table` מחזיק את שורות המחירון לפי מידה. מידה שמופיעה במחירון מקבלת את המחיר שלה. מידה אחרת מחושבת מהמידות הסמוכות (למשל רוחב 175 בין 160 ל־200). אם במחירון יש רק מידה אחת, המחיר משתנה ביחס ישר למידה.

## שולחנות ושלדים (גרסה 1.3)

| קובץ | מוצר |
|---|---|
| `office-desk` | שולחן עבודה |
| `manager-desk` | שולחן מנהל |
| `desk-frame` | שלד לשולחן (ברירת מחדל: בלי פלטה) |
| `bench-desk` | עמדות עבודה משותפות (בנץ׳ וזוג מול זוג) |

17 דגמי שלד מתוך מחירון הייבוא של Modulartech (ינואר 2026): אינטל, רוז, לוטוס, איקס, ורונה, לאטה, ארקו, קואדרו, ג׳וי פתוח, ג׳וי סגור, בארי, ונציה, פלאי, ברצלונה, גשר, ספיידר ושולחן חשמלי.
תצורות: שולחן יחיד, שורת שולחנות (רוכבים), זוג מול זוג, בנץ׳ ארבע עמדות – לפי מה שקיים לכל דגם.
מחיר הפלטה נקבע לפי כמה פלטות יוצאות מלוח 280×210 (אחת עד ארבע), כמו במחירון. צבע RAL שאינו לבן, שחור, גרפיט או כחול: ‎+70 לשלד, ‎+120 לבנץ׳.
את הנתונים מייצר הסקריפט שבתיקיית הכלים; אפשר גם לערוך את קובצי ה־JSON ישירות.

## מידה שהלקוח מקליד

לכל בחירה מסוג `seg` אפשר להוסיף `custom` עם טווח. מופיע כפתור "אחר" ושדה הקלדה. מידה מחוץ לטווח מתעדכנת לקצה הטווח, והלקוח מקבל הודעה.

```json
"custom": { "label": "אחר", "min": 100, "max": 180, "step": 1, "unit": "ס״מ" }
```

כדי להוריד את האפשרות, מוחקים את השורה `custom`.

## מוצר בלי מחיצות או בלי קנט מדוקק

מוחקים מקובץ המוצר את הסקשן או את הבחירה. למשל, כדי ששולחן מסוים יימכר בלי מחיצות, מוחקים את כל הסקשן `"id": "screen"`. השולחן יוצג בלי מחיצות, והאפשרות לא תופיע ללקוח.
אותו דבר עם `prof` (קנט מדוקק), `tray` (מגש כבלים) ו־`power` (קופסת חשמל).

## הוספת מוצר

1. מעתיקים את `products/duo-bench.json` לשם חדש, למשל `products/duo-bench-xl.json`.
2. משנים שם, אפשרויות, ברירות מחדל ומחירים. אפשר לצמצם רשימה משותפת עם `"items": ["oak", "walnut"]` על בחירת הדקור.
3. בדף המוצר: `data-product="duo-bench-xl"`.

מוצר ממשפחה חדשה (ארון, בוט) צריך גם קובץ ב־`src/families/`.

## פיתוח

```bash
npm install
npm run build      # בונה את dist/mrcfg.min.* מתוך src
npm run dev        # שרת מקומי: http://localhost:8080/examples/
```

אחרי כל שינוי בקוד: `npm run build`, commit, Release חדש, ועדכון מספר הגרסה בקוד ההטמעה.
שינוי בקובץ JSON (מחירים, אפשרויות) לא דורש build, רק commit ו־Release.

## קישור שיתוף
